# LUMAMATTERS manual

User manual for the LUMAMATTERS beta: open the **[Wiki](https://github.com/LMXtinker/LUMAMATTERS-manual/wiki)** tab.

The pages live in `wiki/` and are published to the Wiki automatically on every push (`.github/workflows/publish-wiki.yml`). Do not edit pages in the wiki web editor; the next publish overwrites them. The source is kept in the app's own (private) repository.
