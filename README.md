# LUMAMATTERS manual

The manual site lives at https://lumamatters.lumalux.at/manual/ ; this repo holds the wiki and the manual source (its GitHub Pages site only redirects there).

User manual for the LUMAMATTERS beta: open the **[Wiki](https://github.com/LMXtinker/LUMAMATTERS-manual/wiki)** tab.

Web demo: https://lumamatters.lumalux.at/demo/ (runs in your browser, nothing is uploaded). `demo/` holds the built demo only; © 2026 LumaLux, free beta, see [LICENSE](demo/LICENSE) and the [third-party notices](demo/THIRD_PARTY_NOTICES.txt).

The pages live in `wiki/` and are published to the Wiki automatically on every push (`.github/workflows/publish-wiki.yml`). Do not edit pages in the wiki web editor; the next publish overwrites them. The source is kept in the app's own (private) repository.
